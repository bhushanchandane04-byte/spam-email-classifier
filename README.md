# Spam Email Classifier 📧🤖

A machine learning project built with Python and Scikit-Learn to automatically detect and filter spam emails based on their content using Natural Language Processing (NLP).

## 🚀 Features
* **Text Vectorization:** Converts raw email text into numerical features using **TF-IDF (Term Frequency-Inverse Document Frequency)**.
* **Classification Model:** Uses a **Multinomial Naive Bayes** classifier to separate emails into `spam` or `ham` (legitimate).
* **Evaluation:** Includes accuracy metrics and a classification report.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn
